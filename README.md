## Demonstração

- Visualize o site localmente abrindo `index.html` no navegador.
- Hospedado na Vercel: https://helio-portfolio.vercel.app/


**Como rodar localmente**

1. Clone o repositório:

```
git clone https://github.com/MrHelio/helio-portfolio.git
cd helio-portfolio
```

2. Abra o arquivo `index.html` no navegador (duplo-clique ou `Ctrl+O` → abrir).

3. (Opcional) Se usar um servidor local (recomendado para rotas/SPA):

```
# usando Python 3
python3 -m http.server 8000
# ou usando npm 'serve' (se instalar)
npx serve .
```

Abra `http://localhost:8000` no navegador.
